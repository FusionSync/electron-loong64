Electron 37.2.2 for UOS Loong64 (old ABI)

This release contains the verified LoongArch64 Electron bundle built for UOS 20 / glibc 2.28. The bundle includes the Electron runtime, Chromium shared libraries, embedded `libffmpeg.so`, mksnapshot, chromedriver, Node headers, libcxx assets, and the local functional test programs.

Artifact: `electron37.2.2-linux-loong64-bundle.zip`
SHA256: `36ba13e6d49e7c24e890e5baa8b9a07bdf68d8b6a1d40606b4274568a073fea4`

Validation performed:

- ELF machine 258 / LoongArch64, UOS old-ABI flags `0x3`
- imported glibc symbols no newer than 2.28
- archive CRC and required runtime assets
- Electron `--version` and real window/page tests on a UOS Loong64 desktop
- network page tests and local animation/file/IPC tests

The final link used the recorded GNU binutils fix for the LoongArch type-44 relocation mask. The repository contains the source pins, patch manifests, local compatibility patches, Docker recipe, and audit scripts. Chromium objects, UOS sysroot binaries, toolchains, and the native builder base image remain separate because of size and redistribution constraints.

A clean third-party rebuild from only the Git tree has not yet been independently completed; use the matching base image and UOS input files documented in `inputs/README.md` and verify their SHA256 values before building.
