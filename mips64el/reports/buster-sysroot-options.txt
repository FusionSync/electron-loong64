Complete sysroot construction plan
1. Pin the Packages index above and resolve all target runtime/development
   dependencies for the current Chromium package list, including arch=all
   packages from the same Buster archive. Verify every package's SHA256.
2. Extract packages with dpkg-deb -x into a fresh separate sysroot; no MIPS
   executable needs to run for this step. Preserve runtime code and MIPS ABI
   sections. Repair absolute symlinks to stay within the new root.
3. Ensure pkg-config uses only the new target root and confirm GTK/CUPS/NSS/
   X11/GBM/ALSA/udev metadata. Rebuild target CRT and runtime dependencies if
   a chosen newer toolchain introduces symbols newer than glibc 2.28.
4. Build into a separate output directory. Audit every release ELF's required
   GLIBC versions and test the complete application on the real 3A4000 system.

Replacing only libc6 files inside a Bullseye sysroot is insufficient: other
Bullseye libraries can require newer glibc symbols. Keep a complete Buster
package set together and verify the final ELF requirements.
