Bootstrap corrections
---------------------
* Explicitly disable all seven Chromium Bullseye GCS sysroot dependencies.
  Electron's install_sysroot=False only disables its own hooks. It does not
  suppress Chromium's separate DEPS downloads. Buster is supplied independently
  by the recipe rather than downloaded into the source tree by gclient.
* Set cache_dir=None so a user-wide GIT_CACHE_PATH does not select an external
  shared Git cache for this standalone checkout.
* Recover initialization interrupted between git init and git remote add.
  A conflicting origin or HEAD still causes a refusal; nothing is reset.
* After hooks, require nonempty host GN, host Rust, Electron Yarn integrity,
  DAWN_VERSION, OpenGL registry XML, and EGL registry XML inputs. Missing inputs
  are reported before a partial source cache reaches GN/Ninja.

Pinned upstream inspection
--------------------------
* depot_tools accepts the configured shallow/no-history/no-hook flags.
* depot_tools uses target_cpu='mips64'; GN's target_cpu is 'mips64el'.
* Chromium recurses into Dawn's DEPS. Its normal hooks generate DAWN_VERSION;
  Dawn DEPS supplies both Khronos registries. A small checkout retains these.
* Official patch ordering is patches/config.json order, then each directory's
  .patches order. The helper calls Electron's official patch-loading and Git
  import functions; it does not substitute a LoongArch patch stack.
* Patch state records each repository's base, combined patch SHA256 and result.
  Interrupted git am, changed HEAD, tracked modifications and changed completed
  patch inputs are rejected for manual review. No implicit reset is performed.

Local fixture results: all 8 check groups passed
----------------------------------------------
1. Generated configuration: source pins, CPU selectors, seven GCS exclusions,
   disabled automatic patches/sysroots, and disabled global Git cache.
2. Empty workspace creation, repeated initialization, and missing-origin repair.
3. Refusal of wrong origin, changed configuration/pins and unmarked directories.
4. Real local Git fetch/checkout at a fixed depot commit, successful resume,

5. Hook-input validation rejects missing/empty files and accepts complete files.
6. Mocked orchestration confirms sync -> actual revision log -> official patches

   upstream refs, idempotent resume, and refusal of interrupted/dirty/changed
   repositories all passed.
8. Both public Python helpers compile without syntax errors.

Limits
------
These checks validate configuration, local Git/patch behavior and error paths.
They are not proof of a successful complete clean network sync, complete
Electron build, real 3A4000 execution or a working GUI. The source bootstrap
remains experimental until those checks are completed separately.

Some upstream DEPS entries use version tags rather than immutable SHA values;
the bootstrap records resolved revisions before patches, but does not replace
every transitive upstream selector with a separately locked commit. GitHub,
Google Git/GCS/CIPD and npm downloads must remain available. A partial copied
source tree cannot replace recursive gclient sync plus successful hooks.
